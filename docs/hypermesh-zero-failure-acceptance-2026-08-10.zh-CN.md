## 失败原因与有效优化

优化前基准有 C2/A16/S5/H91，共 100 个唯一失败单元、21 个热点。
100/100 个失败单元与边界关联，99/100 个有两个及以上边界节点，表明
质量瓶颈主要来自 CAD 边界采样、曲面三角形和四面体过渡。继续盲目
加密会进一步压低绝对最小高度。

有效路线如下：

1. 使用两层邻域、feature-aware `*morphsmoothmorphbased` 对边界平台期进行
   保形正则化，降至 C0/A0/S1/H4。
2. 对四个高度残差使用一层局部 free morph，降至 C0/A0/S1/H0。
3. 对最后一个内部偏斜残差及 35 单元邻域执行固定边界 `*tetmesh` mode 6，
   达到 C0/A0/S0/H0。
4. 保存 HM、导出 FEM、独立重载并再次进行全模型质量与单元类型审计。

全新表面/体网格重建、统一 mode 8 重构、全局重复优化、强制投影到陈旧
几何 ID 等候选均因效果不佳或产生质量退化而被回滚。

## MCP 与 Skill 更新

HyperMesh MCP 已由 0.8.1 更新到 0.9.0，新增
`hypermesh_plan_tetra_zero_failure_search`，固化以下逻辑：

- 检测优化平台期和边界主导比例；
- 保形 morph 的一层/两层参数候选；
- 高度残差与内部偏斜残差分流；
- mode 6/7/8 边界自由度的明确区分；
- checkpoint、全指标复测、严格回滚与独立重载；
- 纯 Tet4、精确最差值、节点位移及 CAD 关联审计；
- 数值质量验收与几何贴合验收分开。

Skill 的孔、圆柱、球体、法兰、圆角和倒角处理规则保持不变，并增加上述
零失败平台期升级及几何偏移审计。专用测试 29/29 通过，Ruff 检查通过。

## 工程边界

本轮四项数值质量验收完成，但 Minimum Height 通过裕量仅约 0.000055 mm；
567 个节点发生局部移动，最大边界位移为 1.432328839 mm。正式仿真前应由
项目负责人按接触、公差、载荷和应力关注区域给出允许几何偏移。没有该
容差时，不应把“四项零失败”自动等同于“几何贴合已批准”。
