- [ ] Source CAD copied without overwriting the original.
- [ ] Import translator and return code recorded.
- [ ] Imported surface/solid/component counts are nonzero.
- [ ] Free edges, duplicates, intersections, normals, and topology audited.

- [ ] Named quality limits and failed counts exported.

- [ ] `.hm` and nonempty downstream solver deck exported.
- [ ] Tcl, command line, hmbatch/BatchMesher logs, and report retained.
