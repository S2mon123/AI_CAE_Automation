# LAMMPS And OVITO Evidence Chain

## LAMMPS

- [ ] Executable version/build and packages recorded.
- [ ] Units, atom style, boundaries, masses, potential provenance/license, and seeds recorded.
- [ ] Minimization, equilibration, loading, and production phases separated.
- [ ] Requested step count completed without lost atoms or fatal errors.
- [ ] Thermo history, final data/restart, and trajectory retained.
- [ ] Stress/strain or other derived quantity includes conventions and a versioned script.

## OVITO

- [ ] GUI availability and batch-Python availability reported separately.
- [ ] Input trajectory, frame range, properties, and periodic boundaries recorded.
- [ ] Modifier parameters, reference frame, cutoff, camera, color range, and render size recorded.
- [ ] PNG/MP4 and numeric table exported when applicable.
- [ ] Native OVITO output distinguished from fallback plotting.

## Claims

- [ ] OVITO rendering is not used as upstream solve proof.
- [ ] Potential redistribution rights were checked before publication.
- [ ] Size, rate, seed, and model limitations constrain material-property claims.
