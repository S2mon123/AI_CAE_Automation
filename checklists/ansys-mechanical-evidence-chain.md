# Ansys Mechanical Evidence Chain

- [ ] Workbench/Mechanical version and selected control route recorded.
- [ ] Geometry scale, units, materials, contacts, loads, supports, and solver controls audited.
- [ ] Element/node counts and relevant quality metrics exported.
- [ ] Mechanical analysis state is `Solved`.
- [ ] MAPDL solve log exists and reports normal termination.
- [ ] Reactions balance applied loads within the stated tolerance.
- [ ] Expected nonempty `.rst` exists.
- [ ] Numeric CSV/JSON export exists.
- [ ] Native result image exists.
- [ ] Contact, singularity, weak-spring, stabilization, and convergence warnings are discussed.
- [ ] Mesh/contact sensitivity and benchmark status determine the final credibility grade.
